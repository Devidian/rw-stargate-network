# OZ Stargate Network 0.1.0

WebSocket/MongoDB companion for **OZ - Stargate 0.1.0**.

- Persistent gate registration, online address discovery and remote dialing.
- Durable inventory transfer coordination with release/claim states, reconnect recovery and pre-claim expiry.
- Per-server player observations and bounded protocol-v1 messages.

Docker: `devidian/rw-stargate-network:0.1.0` (linux/amd64 and linux/arm64). See `docker-compose.example.yml`; MongoDB storage must persist.

**Deployment scope:** restrict access to trusted game servers and terminate TLS at your proxy. The deterministic network code is not authentication. This release does not provide a public trusted transfer service or change access to the existing hosted relay.
