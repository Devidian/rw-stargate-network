# OZ Stargate Network 0.3.0

WebSocket/MongoDB companion for **OZ - Stargate 0.3.0**.

- Extend the outgoing seven-chevron cadence to seven seconds per lock for synchronized DHD, ring and chevron cues.
- After target acceptance, show the source gate as open immediately. The target activates seven incoming chevrons at 400 ms intervals; the relay creates the travel window only after the 2.8-second sequence.
- Preserve the full incoming sequence for a valid target reply near its ten-second deadline. Open connections retain a 60-second travel window; inventory transfer recovery is unchanged.

Docker: `devidian/rw-stargate-network:0.3.0` for linux/amd64 and linux/arm64. Persist MongoDB data, upgrade the relay before OZ - Stargate 0.3.0, and ensure no transfer is active during the change. Protocol v1 and database schemas are unchanged.

Use only with a controlled group of trusted servers behind TLS. The deterministic network code is routing metadata, not authentication. This release does not make the hosted test relay public.
