# OZ Stargate Network 0.5.0

Relay companion for **OZ - Stargate 0.5.0**. Upgrade the relay first.

- Stores optional Stargate aliases and local plus globally dialable network addresses. Players can see their preferred label in the DHD, with a local address as fallback when available.
- Gives a newly registered local gate a separate network address without replacing its local identity. Existing gates keep their IDs and receive local-address metadata when their server reconnects.
- Keeps protocol v1 and existing gate, address-book and transfer data compatible. Gate registration, aliases and legacy local-address updates remain scoped to the owning server.

Back up MongoDB and participating plugin/player databases before upgrading. Finish active cross-server transfers before any rollback. Network codes group servers but do not authenticate them. Docker image: `devidian/rw-stargate-network:0.5.0` for linux/amd64 and linux/arm64.
