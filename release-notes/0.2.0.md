# OZ Stargate Network 0.2.0

WebSocket/MongoDB companion for **OZ - Stargate 0.2.0**.

- Coordinate seven-chevron dialing, progress and gate state. An incoming connection interrupts an unfinished outgoing sequence; established wormholes close after their configured window.
- Keep gate registration and globally unique address reservation available when a plugin has cross-server travel disabled.
- Preserve durable transfer claim and recovery behavior; an already claimed transfer still requires explicit review rather than automatic abort.

Docker: `devidian/rw-stargate-network:0.2.0` for linux/amd64 and linux/arm64. MongoDB data must persist. Upgrade the relay before enabling 0.2.0 plugin travel, and ensure no transfer is active while changing versions.

**Deployment scope:** use only with a controlled group of trusted game servers behind TLS. The deterministic network code is routing metadata, not server authentication. This release does not make the existing hosted relay public. NPC travel is deferred.
