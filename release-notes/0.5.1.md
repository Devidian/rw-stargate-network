# OZ Stargate Network 0.5.1

Relay companion for **OZ - Stargate 0.6.0**. Upgrade the relay before the plugin.

- When a server changes its network code, move only that server's gates and learned addresses to the new code. Other servers' address books remain under their original code.
- Check address collisions before moving gates. The relay retains protocol v1 and existing gate and transfer records.

Back up MongoDB and the participating plugin and player databases before upgrading. Complete active transfers before rollback. This release publishes the relay image; it does not deploy it to a production game server.
