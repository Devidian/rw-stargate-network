# OZ Stargate Network 0.4.1

Relay companion for **OZ - Stargate 0.4.1**. Protocol v1 and MongoDB schemas are unchanged.

- The hosted TLS proxy accepts Stargate servers from arbitrary IP addresses. Servers are grouped automatically by the existing computed network code or an administrator's `networkCode.override`.
- A public nginx `/ws` proxy example is included with the release. It forwards the actual client IP in `X-Real-IP` so the plugin can discover its advertised game host.

Network codes and observed IPs are routing information, not authentication. Administrators who want isolation can set an unpredictable override and share it only with intended peers. A client can still claim server and player identities; do not treat peer data as authenticated. Future network-code rules may add factors without changing the meaning of this release.

Back up MongoDB and participating plugin/player databases before upgrades. No relay runtime upgrade is required solely to remove a host-specific IP allowlist; configure and test the TLS proxy separately. Docker image: `devidian/rw-stargate-network:0.4.1` for linux/amd64 and linux/arm64.
