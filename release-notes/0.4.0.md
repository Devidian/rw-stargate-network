# OZ Stargate Network 0.4.0

Relay companion for **OZ - Stargate 0.4.0**.

- A personal address book stores discovered gate IDs by network and player. Repeated discoveries are safe to resend; deleting a gate removes it from all matching books and notifies connected servers.
- A server without an advertised game address can request the public IPv4 observed by the TLS proxy. The proxy must overwrite `X-Real-IP`; servers on the relay's local Docker network may use `LOCAL_GAME_PUBLIC_IP`.
- Existing gates, transfers and protocol v1 remain compatible. Existing address books begin empty.

Back up MongoDB and the participating servers' plugin and player databases, finish active transfers, then upgrade the relay before OZ - Stargate 0.4.0. Docker image: `devidian/rw-stargate-network:0.4.0` for linux/amd64 and linux/arm64. Keep the relay restricted to trusted servers; network codes and observed IPs are routing metadata, not authentication. This release does not open the hosted test relay to the public.
